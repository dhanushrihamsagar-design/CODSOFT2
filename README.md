# 📊 Sales Data Analysis & Power BI Dashboard

## 📌 Project Overview

This project focuses on analyzing sales data to understand overall sales performance, product performance, monthly trends, geographical sales, deal sizes, and customer performance.

Python was used for data cleaning and preparation, and Power BI was used to create an interactive Sales Performance Dashboard.

## 🎯 Objectives

* Clean and preprocess the sales dataset
* Analyze overall sales performance
* Analyze sales by product line
* Identify monthly sales trends
* Compare sales across countries
* Analyze sales by deal size
* Identify the top 10 customers by sales
* Create an interactive Power BI dashboard

## 🛠️ Tools & Technologies

* Python
* Pandas
* Jupyter Notebook
* Power BI Desktop
* CSV

## 🔄 Project Workflow

1. Imported the sales dataset into Python.
2. Cleaned and prepared the data using Pandas.
3. Saved the cleaned data as `sales_cleaned.csv`.
4. Imported the cleaned data into Power BI.
5. Created KPIs and visualizations.
6. Built a Sales Performance Dashboard.

## 📊 Power BI Dashboard

The dashboard includes:

* 💰 **Total Sales**
* 📦 **Total Quantity Ordered**
* 📊 **Sales by Product Line**
* 📈 **Monthly Sales Trend**
* 🌍 **Sales by Country**
* 🍩 **Sales by Deal Size**
* 🏆 **Top 10 Customers by Sales**

## 🔍 Analysis Areas

The dashboard provides insights into:

* Overall sales performance
* Product line performance
* Monthly sales patterns
* Geographical sales performance
* Sales distribution by deal size
* Customer sales performance


## 🚀 Conclusion

This project demonstrates a complete data analytics workflow, from data cleaning and preparation using Python to data visualization and dashboard development using Power BI.

The project helped develop practical skills in data preprocessing, data analysis, visualization, and business intelligence.
